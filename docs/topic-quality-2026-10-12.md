## 規則與來源保留

- 原始 tag 詞條、大小寫與 payload 全數保留。派生 canonical ID 為 NFKC＋大小寫正規化後的 SHA-256，跨快照穩定；舊 ID 透過別名解析。顯示寫法取同一來源快照中 articleCount 最高的原寫法，同數按原 ID 決定。
- 逐字移植 tag `afe0a653fa8aae7e25a04a1d9fe87bf0400a2a39` 的 `isTagNoise` 與 `no-equal-tags.json`。no-equal 原本比顯示雜訊更廣，此處依使用者指示用作比對排除；不宣稱所有排除詞都不是合法主題。
- 「推薦」保留但標為 tag-noise，「時間」標為 no-equal，「2026」為 pure-number，「性」為 too-short。排除詞仍可由原話題 ID 查詢原因，資料不刪除。
- 只比對標題與清理後正文；RSS 分類保留來源紀錄，可對應來源詞庫，但不另建排行詞典。推薦／相關文章區塊、獨立日期／分類列以 HTML 結構排除，一般正文句子不直接刪除。沒有 HTML 的舊正文採保守行清理，不臆測片段界線。
- 同篇標題與正文取最高權重（標題 2、正文 1）且只算一篇；同站按權重排序後每篇依序減半。2 篇標題＋1 篇正文為 2＋1＋0.25＝3.25；3 篇僅正文為 1＋0.5＋0.25＝1.75。
- 來源池仍合法、實際出現在正文的「選擇」「比較」等詞可能保留在排行；本輪沒有額外新增主觀禁詞字典。

## 部署與回滾

新增 Drizzle migration `0013_topic_matching_quality` 的四張派生表，保留舊 topic_matches／topic_post_indexes。正式 DB 寫入前完整備份；先分批重建近 90 天、確認 pending=0，再切換 gateway／web／worker。重建使用既有 job lease 與每天 10,000 篇預算，不佔 tag 的 API 額度，也不更改 tag／youtube。

新版 worker 之後續跑其他歷史文章；目前公開話題窗口上限為 90 天。回滾先停 blog worker，再切回前一 release；若後續詞庫同步已切換快照，需先將 topic_current 還原到切換前保存的快照 ID。原始及舊索引保留，無須刪除新增資料表。

完整詞庫快照的啟用另等 tag thread 明確通知；本輪沒有切換同步來源、擴充抓取頻率或重新抓取 tag 文章。
