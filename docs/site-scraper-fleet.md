# 逐站抓取器

2026-10-29，10 個 GPT 6.1 Sol agents 針對當時尚無專用抓取器的 359 個官方名錄網站逐站讀取公開列表與文章。定義保存在 `data/site-scrapers/<blogId>.json`；無法讀取、沒有作者文章或無法確認出版者的網站保留原因，不啟用猜測的解析器。

## 驗證與安裝

`tools/validate-site-scraper.ts <definition.json> <private-report.json>` 透過既有安全抓取、渲染與沙箱，從實際列表抽查最多三篇文章。報告綁定整份定義與程式碼的 SHA-256。

`tools/install-site-scrapers.ts` 預設僅預覽；`--apply` 啟用通過驗證的版本。可用 `--ids 1,2` 限定網站，`--output` 寫入私人操作紀錄。驗證須在 24 小時內，網站 ID、首頁、定義與程式雜湊必須完全相符。每站短交易鎖定部落格並保留已有的啟用抓取器；重跑不建立重複版本。驗證、啟用與來源證據一起保存。沒有文章的已收錄站會重排文章補抓。

搬遷至另一個網站 ID 已有的部落格時，沿用既有目標站，不將來源抓取器裝到另一站。來源紀錄與歷史文章保留。需要變更首頁的站必須先核對官方重新導向或明示的作者部落格連結，保留原網址、名錄證據及稽核紀錄。

## 方格子與真實短文

方格子沙龍／作者首頁與文章位於不同 URL 路徑。列表只提供文章候選；受信任抓取器讀到文章頁的 `__NEXT_DATA__.props.pageProps.parsedArticle` 後，核對文章 ID、沙龍 ID 與作者 ID，才能驗證與寫入。沙箱輸出不能自行宣告所有權，重新導向另一篇文章也不能以原文章網址寫入。抓取器包裝、內文更新與資料庫內容寫入均保留並檢查這份證據。

短文、詩與照片文沒有最低字數要求。少於 200 字元的抽樣正文須實際出現在抓取的頁面；輸出照片必須全部存在原頁，不能混入另一張圖片。標題、文章歸屬與不同文章內容仍須驗證。

啟用後沿用既有 feed／專用抓取器選擇與內文更新排程。RSS 正常的站可繼續使用 RSS；成功但沒有文章的 feed 不會擋住已驗證修復。安裝工具不改收錄資格、不調整人工拒收決定，也不修改抓取器沙箱或 HTTP 403 處理。
