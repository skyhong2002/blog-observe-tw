# PR #7 合併前後對照

**所有圖片只有兩個版本：左邊「合併前 main `ebffbef`」，右邊「合併後 `e5c9830`」。** 合併後是本分支最新 UI；其後只有文件與截圖整理。中間各輪、review 回饋前後的圖片已移除。

2026-11-16 在 skyhong-SM 全部重拍，兩邊使用同一份離線快照與固定時鐘（2026-11-13 02:20 台北），不讀正式站或共用 tag-db。每張圖都標出版本、寬度與外觀；桌機 1440、手機 390，深淺色分開成對。長頁面最多截 2700 px／手機 1688 CSS px，底部截斷屬於拍攝方式。

兩邊伺服器都阻擋對外連線，文字雲只顯示文字；正式站可顯示圖片。新版首頁的 100 個候選取自同一快照的升溫話題（與原首頁的前 60 筆相同），用來重現新版 gateway 的回應。話題表格的部落格清單是**示意 fixture**：只有 AI 列是真實清單，其他列按快照目錄補足該列的部落格數；不能從截圖判斷實際有哪些部落格寫過。未快取的圖示顯示字母替代圖。

每個頁面收合區內依序為 1440 淺色、390 淺色、1440 深色、390 深色；額外狀態只拍淺色。共 66 張並排圖，來自 132 張原圖。
